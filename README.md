# Saanidhya Chauhan — Portfolio

Plain HTML/CSS/JS build of the portfolio — navbar with light/dark mode, horizontal-scroll sections, folder-style projects, and a downloadable resume.

## Run it

Just open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

No build step needed.

## Files

```
index.html    — markup for all six sections + navbar
style.css     — all styling, incl. light/dark theme variables
script.js     — horizontal-scroll (GSAP), theme toggle, mobile nav, folder open/close
your-photo.jpg                    — your hero photo
Saanidhya_Chauhan_Resume.pdf      — linked from the download-resume icon in the hero
```

Swap `your-photo.jpg` or the resume PDF for updated versions any time — same filenames, so nothing else needs to change.

## Deploy

Push the whole folder as-is to GitHub Pages, Vercel, or Netlify — it's fully static.
